# Concept Progression Modules

Ordered progression based on the proposal:

1. Introduction to Strings
2. String Indexing and Zero-Based Counting
3. String Slicing and Exclusive End Bounds
4. String Immutability
5. String Comparison
6. Looping Through Strings
7. String Length and Built-in Methods
8. String Formatting

## Suggested Gating Rule

- Require a minimum score (for example, 70%) to unlock the next module.
- Track:
  - `completed`
  - `score`
  - `last_session_at`

## Exercise Types

- Multiple-choice
- Fill-in-the-blank
- Both should map wrong answers to misconception IDs.
